# Standard Label Set

Namespaced `category/name` convention, adapted for smaller projects.

## Type (what kind of change)

| Name | Color | Description |
|------|-------|-------------|
| `type/bug` | `#ee0701` | Something is broken |
| `type/feature` | `#006b75` | New functionality |
| `type/enhancement` | `#84b6eb` | Improvement to existing functionality |
| `type/proposal` | `#5319e7` | Needs discussion before implementation |
| `type/docs` | `#c2e0c6` | Documentation only |
| `type/refactoring` | `#1d76db` | Code cleanup, no new functionality |
| `type/testing` | `#d4c5f9` | Test-related changes |

## Issue Lifecycle

| Name | Color | Description |
|------|-------|-------------|
| `issue/confirmed` | `#8d9b12` | Reviewed and confirmed |
| `issue/duplicate` | `#cccccc` | Already reported |
| `issue/needs-feedback` | `#1d76db` | More details needed |
| `issue/critical` | `#fbca04` | Should be fixed ASAP |

## Proposal Lifecycle

| Name | Color | Description |
|------|-------|-------------|
| `proposal/accepted` | `#22E217` | Approved for implementation |
| `proposal/rejected` | `#486154` | Not accepted |

## Status

| Name | Color | Description |
|------|-------|-------------|
| `status/blocked` | `#B60205` | Cannot proceed, depends on something else |

## PR Status

| Name | Color | Description |
|------|-------|-------------|
| `pr/wip` | `#fbca04` | Not ready for review |
| `pr/breaking` | `#d93f0b` | Contains breaking changes |

## Topic (project-specific — extend per repo)

| Name | Color | Description |
|------|-------|-------------|
| `topic/ui` | `#fef2c0` | Web UI changes |
| `topic/api` | `#A20C87` | API changes |
| `topic/mobile` | `#AFCEB5` | Mobile / Flutter app |
| `topic/security` | `#0052cc` | Security-related |
| `topic/deployment` | `#c5def5` | Infrastructure / deployment |
